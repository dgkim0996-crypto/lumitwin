## 1. 목적과 적용 범위
이 표준은 사이드미러 라인(OSM) 폴딩 액추에이터 조립 셀(OSM-AC-01)의 작업 방법을 정한다. 브래킷 사출기(OSM-IM-B1, PA6-GF30)에서 온 브래킷(시리얼 BK…)에 폴딩 모터와 웜기어·클러치 세트를 넣고, 기어 그리스를 정량 도포한 뒤 나사를 체결한다. 사이클은 약 50초다. 액추에이터는 미러 최종 조립 셀(OSM-AS-01)을 거쳐 기능 검사기(OSM-FT-01)에서 시험된다. 그리스 도포량과 체결 상태는 기능 검사의 작동 소음, 모터 전류, 폴딩 시간에 영향을 준다.

## 2. 안전
- 자동 드라이버는 회전체다. 회전부 가까이에서 면장갑을 끼지 않는다. 말려 들어갈 수 있다.
- 그리스 디스펜서는 공압으로 움직인다. 노즐을 청소할 때 공기를 차단하고 잔압을 뺀다.
- 그리스가 피부와 눈에 닿지 않게 보호 장갑과 보안경을 쓴다.
- 지그 클램프에 손이 끼지 않게 한다.
- 디스펜서와 드라이버 정비는 LOTO(잠금·표지) 후에 한다 (WS-COM-01).

## 3. 작업 전 점검
- 자재 LOT를 확인하고 MES에 등록한다: 폴딩 모터, 웜기어·클러치 세트, 기어 그리스. LOT가 바뀌면 바로 등록한다. LOT 추적의 근거다.
- 시업 때 8절 방법으로 그리스 도포량을 확인한다. 노즐 끝에 굳은 그리스가 없는지 본다.
- 토크 측정기로 자동 드라이버 토크를 확인한다. 기준 0.8 N·m, 0.7~0.9 N·m다.
- 브래킷 외관과 휨을 본다. 브래킷이 휘면 기어 마찰이 커진다.

## 4. 공정 조건

그리스 도포량(기준 120 mg, 100~140 mg)이 가장 중요하다. 그리스가 모자라면 기어 마찰이 커져 기능 검사에서 작동 소음과 모터 전류가 오르고 폴딩 시간도 길어진다. 체결 토크는 0.7~0.9 N·m(기준 0.8 N·m)로 관리한다.

## 5. 작업 순서
1. 브래킷을 지그에 바르게 안착한다.
2. 폴딩 모터를 장착하고 웜기어·클러치 세트를 방향에 맞춰 조립한다.
3. 그리스를 정해진 위치(웜과 기어 치면)에 정량 도포한다.
4. 커버를 덮고 나사를 체결한다. 토크 결과가 기록됐는지 확인한다.
5. 시리얼과 투입 LOT 기록을 확인하고 배출한다.

## 6. 품질 확인
- 그리스 도포량 기록과 추세를 본다. 규격 안이라도 계속 줄면 디스펜서 막힘을 의심한다.
- 체결 토크 기록을 확인한다.
- 기능 검사기(OSM-FT-01)의 작동 소음·모터 전류·폴딩 시간 결과를 액추에이터 조립 이력과 이어서 본다. 액추에이터 조립 셀에는 자체 판정이 없어 이상이 기능 검사에서 드러난다.

## 8. 그리스 도포량 확인 (무게 측정)
폴딩 액추에이터 조립 셀(OSM-AC-01)의 그리스 도포량은 시업 때, 노즐 교체·청소 후, 그리스 통 교체 후, 정해진 주기로 무게를 재서 확인한다.
1. 정밀 저울의 영점을 잡고 시험 용기(또는 시편)를 올려 무게를 기록한다.
2. 디스펜서로 1회 토출한다. 정해진 횟수만큼 반복한다.
3. 무게 차이로 1회 도포량을 구한다. 100~140 mg 안이고 기준 120 mg에 가까워야 한다.
4. 벗어나면 양산을 멈추고 9절 조치를 한다.
5. 결과를 점검 기록표에 남긴다.

## 9. 디스펜서 막힘 대응
그리스 디스펜서 노즐이 막히면 도포량이 한 번에 0이 되지 않고 서서히 준다. 노즐 끝에 굳은 그리스, 토출 끊김, 도포 모양이 가늘어지는 것이 신호다.
1. 설비를 정지하고 공압을 차단·잔압을 뺀다 (LOTO).
2. 노즐을 분리해 세척하거나 교체하고, 필터를 확인한다.
3. 공급 압력과 그리스 잔량을 확인한다.
4. 8절 무게 확인에 합격하면 재가동한다.
5. 도포량이 줄기 시작한 시점 이후 조립한 액추에이터는 범위를 정해 보류하고, 기능 검사 결과를 확인한다 (WS-COM-02).
