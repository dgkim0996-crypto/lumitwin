## 1. 목적과 적용 범위
이 표준은 전장 모듈 라인(EM)의 검사 공정 작업 방법을 정한다. 적용 설비는 LED AOI(EM-AOI-L), BMS 레인 AOI(EM-AOI-B), ICT 인서킷 테스터(EM-ICT-B), FCT 기능 시험기 #1·#2(EM-FCT-B1, EM-FCT-B2), EOL 시험기(EM-EOL-B)다. AOI는 부품 유무·극성·위치·납땜 외관을 카메라로 보고, ICT는 핀으로 회로를 짚어 단락·개방·부품값을 본다. FCT는 컨포멀 코팅 후 전원을 넣고 셀 전압 측정 정확도, 전류, 온도, 밸런싱, CAN 통신을 시험한다. FCT 두 대는 택트를 맞추려고 병렬로 쓴다. EOL은 하우징 체결 후 완제품의 절연저항, CAN 진단 응답, 펌웨어·DTC를 확인한다.

## 2. 안전
- EOL 절연 시험 전압은 500 V다. 시험 중에는 제품과 프로브를 만지지 않고, 커버와 인터록이 정상인지 확인한다.
- ICT 지그 프레스가 내려올 때 손이 끼지 않게 한다.
- FCT 전원이 들어간 상태에서 커넥터를 꽂고 빼지 않는다.
- ESD 손목띠를 착용한다.
- 지그 교체와 시험기 정비는 LOTO(잠금·표지) 후에 한다 (WS-COM-01).

## 3. 작업 전 점검
- AOI: 조명 밝기가 기준 100 % 근처인지 보고, 기준 기판으로 판정이 맞는지 확인한다.
- ICT: 지그 접촉 횟수(천 회 단위)를 확인하고 정해진 횟수에 이르면 프로브 핀을 바꾼다. 핀 오염과 휨을 본다.
- FCT #1·#2: 기준 전압원 3.7 V를 확인하고, 골든 샘플(양품 기준 기판)과 NG 샘플로 판정을 확인한다.
- EOL: 절연 시험 전압 500 V와 기준 저항 측정값을 확인한다.

FCT는 셀 전압 측정 오차 5 mV 이하(기준 1.2 mV), 암전류 120 µA 이하(기준 85 µA)를 합격으로 본다. EOL은 절연저항 100 MΩ 이상(기준 800 MΩ)이 합격이다.

## 5. 작업 순서
1. AOI: 기판을 넣고 자동 판정한다. NG 후보는 리뷰 작업자가 확대 화면으로 보고 진짜 불량과 가성 불량을 가른 뒤 결과를 입력한다.
2. ICT: 기판을 지그에 올리고 단락·개방·부품값을 측정한다. NG 위치를 기록한다.
3. FCT: 컨포멀 코팅(EM-CC-B)이 끝난 기판을 시험기에 물리고 전 항목을 시험한다.
4. EOL: 하우징 체결 셀(EM-HA-B)을 거친 완제품을 시험한다.
5. NG 기판은 불량 코드와 함께 분리한다. 수리한 기판은 해당 검사를 전 항목 다시 한다.

## 6. 품질 확인
불량별로 어느 검사에서 걸리는지 알고 결과를 본다. 앞 공정에서 생긴 잠재 불량은 검사마다 검출률이 다르다. LED AOI(EM-AOI-L)는 LED 레인, 나머지는 BMS 레인 검사다. LED AOI를 빠져나간 LED 냉납은 헤드램프 라인 EOL 점등·통신 검사기(HL-EOL-01)에서 걸린다.

| 불량 | LED AOI | AOI | ICT | FCT | EOL |
|---|---|---|---|---|---|
| 부품 누락(MISSING) | 약 99 % | 약 99 % | 약 99 % | - | - |
| 부품 틀어짐(SHIFT) | - | 약 95 % | 약 70 % | 약 80 % | - |
| 솔더 브리지(BRIDGE) | - | 약 90 % | 약 99 % | - | - |
| 툼스톤(TOMB) | - | 약 95 % | - | - | - |
| 냉납(COLD) | 약 45 % | 약 35 % | 약 60 % | 약 90 % | 약 95 % |

- AOI 통과율은 그대로인데 ICT·FCT 불량만 늘면 냉납을 의심한다 (WS-EM-03).
- FCT #1과 #2의 NG율을 따로 본다. 한 대만 높으면 그 시험기를 먼저 의심한다.

## 7. 이상 발생 시 조치
| 증상 | 의심 원인 | 확인 방법 | 조치 |
|---|---|---|---|
| 부품 누락(MISSING)·부품 틀어짐(SHIFT) 증가 | 마운터 노즐 진공 약화, 노즐 마모 | 불량을 마운터·노즐별로 분류 | 마운터 점검 (WS-EM-02) |
| 솔더 브리지(BRIDGE) 증가 | 인쇄 압력 과다, 페이스트 체적 과다 | 불량 기판의 SPI 이력 | 인쇄 조건 복귀 (WS-EM-01) |
| 툼스톤(TOMB) 증가 | 패드 가열 비대칭, 인쇄 편차 | 부품 위치별 분포 | 리플로우·인쇄 점검 (WS-EM-03) |
| 냉납(COLD): AOI 통과, ICT·FCT·EOL NG 증가 | 리플로우 피크 온도·TAL 저하 | 불량 기판의 리플로우 이력 | 프로파일 측정 (WS-EM-03) |
| 셀 전압 측정 오차 규격 이탈(FUNC) | 솔더 접합 품질 저하, 기준 전압원 틀어짐 | 골든 샘플 측정, 두 FCT 교차 측정 | 시험기 교정 또는 리플로우 점검 |
| 암전류 규격 이탈(CURRENT) | 부품 불량, 오염·브리지로 인한 누설 경로, 슬립 진입 실패 | 부품 LOT, 펌웨어 버전 확인 | 원인별 조치, 부품 LOT 추적 |
| 절연저항 규격 이탈(INSUL) | 컨포멀 코팅 품질 저하(코팅 두께 부족, 스프레이 압력 과다, 경화 온도 저하), 오염·이물 | 불량 기판의 코팅 이력(EM-CC-B) | 코팅 조건 복귀, 해당 기간 기판 재검 |
| FCT 한 대만 NG 증가 | 시험기 핀·커넥터 마모, 기준 전압원 이상 | 같은 기판을 두 시험기에서 교차 측정 | 시험기 정비 후 NG 재판정 |
| AOI 가성 불량 증가 | 조명 밝기 저하, 카메라 오염 | 기준 기판 판정 | 조명·카메라 정비 |

## 8. 검사 설비 점검
- 시업과 교대 때 골든 샘플과 NG 샘플로 각 검사기 판정을 확인한다. 골든 샘플이 NG로 나오거나 NG 샘플이 통과하면 양산 판정을 멈춘다.
- FCT #1·#2는 같은 기판을 두 대에서 재 결과가 일치하는지 정해진 주기로 확인한다.
- ICT 프로브 핀은 지그 접촉 횟수 기준으로 교체하고 교체 이력을 남긴다.
- AOI 판정 프로그램과 기준값을 바꿀 때는 품질 담당 승인을 받는다.
- 점검에서 이상이 나오면 직전 점검 이후 판정한 기판을 보류하고 재판정한다 (WS-COM-02).
