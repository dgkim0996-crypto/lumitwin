## 1. 목적과 적용 범위
이 표준은 헤드램프 라인(HL) 배광·에이밍 검사기(카메라식, HL-PH-01)의 검사 방법을 정한다. 기밀 검사를 통과한 헤드램프를 암실에서 점등하고 빔을 촬영해 컷오프 위치·각도와 최대 광도를 잰다. 판정 항목은 수직 광축과 최대 광도이며, 배광 법규 기준을 양산용으로 줄인 것이다. 검사 사이클은 약 55초다. 합격품은 EOL 점등·통신 검사기(HL-EOL-01)로 간다.

## 2. 안전
- 암실은 어둡다. 통로에 물건을 두지 않고, 들어간 뒤 눈이 적응할 때까지 기다린다. 비상 조명과 출구 표시를 확인한다.
- 고휘도 LED 빔을 직접 보지 않는다. 점등 중에는 램프 정면에 서지 않는다.
- 램프 전원 커넥터는 전원이 꺼진 상태에서 꽂고 뺀다.
- 지그, 카메라, 스크린 정비는 LOTO(잠금·표지) 후에 한다 (WS-COM-01).

## 3. 작업 전 점검
- 암실 조도가 상한 2 lux 아래인지 본다. 기준은 0.5 lux다. 문틈과 표시등에서 빛이 새는지 확인한다.
- 기준 램프(마스터 램프)를 측정해 수직 광축과 최대 광도가 평소 기록 범위 안인지 확인한다.
- 램프 고정 지그 기준면에 이물과 마모가 없는지 본다.
- 카메라 렌즈와 스크린의 오염을 확인한다.

## 4. 공정 조건
{{조건표:HL-PH-01}}

수직 광축은 -0.3~+0.3 ° 안이어야 하고(기준 0 °), 최대 광도는 32 kcd 이상이어야 한다(기준 38 kcd). 암실 조도가 높으면 컷오프 판독이 흔들릴 수 있으므로 0.5 lux 수준을 유지한다.

## 5. 작업 순서
1. 램프를 지그에 장착하고 기준면에 밀착시킨다.
2. 전원을 연결하고 로우빔과 하이빔을 점등한다.
3. 카메라로 빔을 촬영해 컷오프 위치·각도와 최대 광도를 자동 측정한다.
4. 결과가 시리얼과 함께 MES에 기록됐는지 본다.
5. OK 램프는 EOL 검사로 보낸다. NG 램프는 불량 표를 붙여 NG 랙에 두고, 재검은 정해진 횟수까지만 한다.
6. 교대와 수리 후에는 기준 램프를 다시 측정한다.

## 6. 품질 확인
- 수직 광축의 평균이 한쪽으로 쏠리거나 산포가 커지는지 관리도로 본다 (WS-COM-03).
- 최대 광도가 하한 쪽으로 내려가는 추세면 리플렉터 반사율을 의심하고 진공증착기(HL-VM-01) 배치 조건을 본다.
- 광축 NG가 늘면 검사기만 보지 말고 LED 모듈의 LED 장착 편차를 확인한다 (8절).

## 7. 이상 발생 시 조치
| 증상 | 의심 원인 | 확인 방법 | 조치 |
|---|---|---|---|
| 수직 광축 규격 이탈(AIM) 증가, 기준 램프는 정상 | LED 모듈의 LED 장착 편차 증가(전장 라인 LED 마운터 EM-MT-L 노즐 마모) → 램프 조립 셀(HL-AS-01)에서 광원 정렬 편차 | 8절 순서로 광축 NG 램프의 LED 모듈 시리얼을 따라가 마운터 장착 편차 확인 | 전장 라인에 노즐 점검·교체 요청, 해당 LED 모듈 격리 (WS-COM-02) |
| AIM 증가, 기준 램프도 틀어짐 | 카메라·스크린 위치 틀어짐, 지그 기준면 마모 | 기준 램프 반복 측정 | 검사기 교정 후 NG 램프 재판정 |
| 최대 광도 규격 이탈(LUX) 증가 | 리플렉터 반사율 저하(Al 막두께 부족, 챔버 압력 상승, 리플렉터 표면 조도 악화), 광축 틀어짐 | 리플렉터 시리얼로 증착 배치 조건과 리플렉터 BMC 사출기(HL-IM-R1) 이력 확인 | 증착·사출 조건 복귀 |
| 암실 조도 규격 이탈 | 문 열림, 빛샘, 조명 미소등 | 조도 측정 | 빛샘 차단 후 재측정 |

## 8. 광축 불량 증가 시 상류 추적 (LED 마운터)
수직 광축 NG가 늘면 배광 검사기만 의심하지 말고 LED 장착 정밀도를 확인한다. LED 모듈은 전장 라인(EM) LED 레인에서 만들어 AMR로 램프 조립 셀(HL-AS-01)에 들어온다. LED 마운터(EM-MT-L)의 장착 정밀도는 ±35 µm(3σ)급인데, 노즐이 닳으면 LED 장착 편차가 커지고 이것이 램프의 광원 정렬 편차가 돼 광축이 틀어진다. 전장 라인의 LED AOI는 부품 유무와 납땜을 보므로 이때 전장 라인 불량은 거의 늘지 않는다.
1. 기준 램프로 배광 검사기를 점검한다. 기준 램프가 정상이면 제품 문제로 본다.
2. 광축 NG 램프의 부품 계보(시리얼 HL…)에서 LED 모듈 시리얼(LM…)을 찾는다.
3. LED 모듈의 LED 마운트 이력에서 LED 장착 편차와 노즐 진공을 양품 램프의 LED 모듈과 비교한다.
4. 장착 편차가 크면 전장 라인에 알려 노즐 점검·교체를 요청한다 (WS-EM-02). 노즐 진공이 정상이어도 노즐 끝 마모로 편차가 커질 수 있다.
5. 편차가 커진 시점 이후 LED 모듈은 조립 앞 재고와 이미 조립된 램프까지 범위를 정해 격리한다 (WS-COM-02).
6. 장착 편차가 정상이면 램프 조립 셀의 LED 모듈 체결 상태와 리플렉터 위치를 확인한다.
