# 실행 MES 사용 안내

LumiTwin의 실행 MES 화면을 쓰는 방법과 역할별로 할 수 있는 일을 정리했다. 판정 규칙·가정값과 그 근거는 [DESIGN.md 8장](DESIGN.md#8-실행-mes)에 있다.

> 가상 공장이다. 계정·작업지시·불량·Hold는 모두 시연용이고 실제 데이터가 아니다.

## 1. 로그인과 역할

조회는 로그인 없이 된다. 상태를 바꾸는 일(설비 조작, 시뮬레이터 제어, 작업지시, 불량 판정, Hold, 변경점, 알람 확인)은 로그인한 사람의 역할 권한을 서버가 확인하고 감사 기록에 남긴다.

| 계정 | 이름 | 역할 | 맡는 일 |
|---|---|---|---|
| `op1` | 현장 작업자 | 작업자 | 설비 정지·재가동 사유, 작업 전 점검, 변경점 신고 |
| `lead1` | 라인 조장 | 조장 | 작업지시·생산 계획, 시뮬레이터 제어, 불량 처리 판정 |
| `qa1` | 품질 담당 | 품질 | 불량 처리(MRB) 판정, Hold 설정·해제, 변경점 승인 |
| `mt1` | 보전 담당 | 보전 | 고장 수리 완료, 예방·예지 보전 실시 |
| `admin` | 시스템 관리자 | 관리자 | 모든 권한, 감사 기록 조회 |

- **로그인**: 상단 오른쪽 `로그인` → 로그인 화면(`/login`)의 계정 버튼. 서버에 `DEMO_PASSWORD`를 정하지 않았으면 버튼만 눌러도 들어간다(기본 비밀번호 `demo1234`는 코드에 공개돼 있다. 공개 배포 때는 바꾼다). 정했으면 버튼은 아이디만 채우고, 비밀번호를 넣어 `로그인`을 누른다.
- **바꾸기·나가기**: 사용자 메뉴(이름·역할 배지) → `다른 계정으로 로그인` 또는 `로그아웃`. 관리자에게는 `감사 기록`이 더 보인다.
- 로그인은 8시간 유지된다. 시도는 1분에 10번까지다.
- **공개 링크**: 보기 전용이라 로그인 버튼이 없다. 시연자는 상단 `보기 전용`을 눌러 제어 키를 넣고(`조작 가능`), 그다음 로그인한다.
- **인증을 끈 서버**(`AUTH=off`): 로그인 없이 모든 기능을 쓰고, 감사 기록에는 시스템으로 남는다.

### 버튼이 막히는 이유

버튼은 보기 전용 → 로그인 → 권한 순서로 막히고, 마우스를 올리면 이유가 보인다. 화면의 막기는 안내이고 실제 판정은 서버가 다시 한다(로그인 안 함 401, 권한 없음 403).

| 막힌 이유 | 안내 문구 (예) | 할 일 |
|---|---|---|
| 공개 링크 보기 전용 | 보기 전용 안내 | `보기 전용` → 제어 키 |
| 로그인 안 함 | `로그인이 필요합니다 (…)` | `로그인` |
| 권한 없음 | `Hold 해제 권한이 없습니다 (조장) · 품질·관리자만 할 수 있습니다` | 안내에 나온 역할로 바꾼다 |

## 3. 화면별 사용법

### 3D 공장 `/` (라인 카드)

- 라인 카드 아래쪽에 실행 상태가 있다. `작업지시` 줄은 진행 중 작업지시 번호·기종, `투입 n/수량 · 양품 n`, 다음 작업지시 기종이다. 다음 기종이 다르면 `⇄`가 붙는다. 작업지시가 없으면 `작업지시 기다리는 중`.
- `불량 대기`·`수리대`·`격리` 개수와 `MRB n`(판정 대기)이 보인다. 줄을 누르면 `/orders`나 `/ncr`로 간다.

### 작업지시·계획 `/orders` (생산 ▸ 작업지시·계획)

- **보는 것**: `진행 중`(투입 중이거나 라인 안에 남은 작업지시), `대기 순서 (생산 계획)`, `지난 작업지시`, `공정 인터록 (투입 확인)`(이 라인 게이트 설비의 통과·대기·거부 수, 무응답 통과 수, 사유별 거부, 최근 거부·대기 목록. 통과 수는 서버가 켜진 뒤 센 값). 위쪽에 투입 중 작업지시, 라인에 걸린 기종, 대기 작업지시 수, 다음 기종 변경이 있다.
- **만들기** (`wo.manage`): `작업지시 만들기`에서 기종·수량·메모를 넣고 `만들기`. 대기 순서 끝에 붙는다.
- **대기 줄**: `▲`·`▼` 순서 바꾸기, `수량` 고치기(`저장`·`취소`), `중단`(계획에서 빼기). 수량은 대기 중일 때만 고친다.
- **진행 중 중단**: `중단` → 확인. 라인이 이 작업지시 투입을 멈추고 다음 것을 받는다. 이미 투입한 것은 그대로 흐른다.
- 대기가 3건보다 적으면 자동 계획이 기종을 번갈아 채운다. 앞뒤 기종이 다르면 `⇄ 기종 변경`이 붙고 셋업 시간이 예상 시각에 들어간다.

### 불량 처리 `/ncr` (품질 ▸ 불량 처리)

- **보는 것**: 부적합 목록(최근 300건, 노란 줄 = MRB 판정 대기), 상세(불량·공정·처리·수리·재검사·결말·같은 시리얼의 다른 NCR), `많이 난 불량`. 상세의 시리얼을 누르면 추적 창이 열린다.
- **판정** (`ncr.dispose`): 접수·MRB 판정 대기 건만 정할 수 있다. 메모를 쓰고 `수리`·`재작업`·`폐기`·`특채 (그대로 사용)` 중 하나를 누른다. 폐기·특채는 확인 창이 뜨고 되돌릴 수 없다. 특채는 메모가 필수다.
- 상세의 "처리 기준이 권하는 처리"는 MES 자동 판정 규칙(불량 코드별 기준 → 검사 공정이면 수리 → 아니면 폐기)의 결과다.

**NCR 상태**

| 상태 | 뜻 | 다음 |
|---|---|---|
| `접수` | 열린 직후 (자동 판정이 정하기 전) | 자동 판정 또는 담당자 판정 |
| `MRB 판정 대기` | 처리 기준이 MRB인 불량(광도 미달·코팅 기포·작동 소음). 개체는 불량 대기에 있다 | 담당자 판정 |
| `수리·재작업 중` | 수리대 줄에 있거나 작업 중 | 성공 → 재검사 대기, 실패 → 종결(폐기) |
| `재검사 대기` | 수리 성공, 불량을 검출한 설비의 되돌림 줄에 있다 | 합격 → 종결(수리 합격), 불합격 → 종결 + 새 NCR(폐기) |
| `종결` | 결말: 수리 합격 · 폐기 · 특채 | — |

### 추적·Hold `/trace`

- **보는 것**: 시리얼 계보(정추적·역추적), `자재 LOT 품질`(LOT별 불량률, 회수 범위), `Hold 목록`, `격리 구역`.
- **LOT Hold** (`hold.create`): `자재 LOT 품질`에서 LOT를 골라 `이 LOT Hold`(Hold 칸을 채운다) → 사유를 쓰고 `Hold 걸기`. 같은 자재·LOT에 활성 Hold가 이미 있으면 거부된다.
- **시리얼 Hold**: 계보 창의 `Hold` 버튼으로 칸을 채우거나, 시리얼을 줄바꿈·쉼표로 여러 개(최대 200개) 넣는다. 격리 구역에서 묶음을 골라 `고른 묶음으로 시리얼 Hold 만들기`로 묶을 수도 있다.
- **영향 범위**: Hold를 고르면 그 대상이 조립돼 들어간 맨 위 제품을 상태별로 센다. 완제품(창고·출하 대기)은 회수 검토, 공정 중인 것은 게이트 설비에서 격리될 대상이다.
- **판정** (`hold.release`): `Hold 판정`에서 `해제 (다시 흘림)` 또는 `폐기`를 고르고, 메모(필수)를 쓴 뒤 `해제하기` / `폐기로 끝내기` → 확인.

**Hold 흐름**

```
Hold 걸기 ─▶ 시뮬레이터: 그 LOT를 쓰던 설비는 새 LOT로 바꾸고 창고의 같은 LOT도 막는다
         └▶ 이미 만든 대상이 게이트 설비에 오면 인터록 HOLD로 거부 ─▶ 격리 구역
해제하기 ─▶ 다른 활성 Hold가 걸고 있으면 그 Hold로 옮긴다
         └▶ 아니면 걸렸던 설비로 돌려보내 다시 투입 확인을 받는다
폐기로 끝내기 ─▶ 격리 구역 묶음을 폐기하고, 대상이 다시 나타나면 자동으로 폐기한다
```

### 변경점·초중종물 `/changes` (품질 ▸ 변경점·초중종물)

- **보는 것**: 변경점 목록(시각·설비·4M·종류·내용·출처·초물·승인), `초물 대기 설비`, `초·중·종물 검사 기록`. 라인·4M 분류·검사 종류·기간으로 거른다. 위쪽에 초물 대기 설비 수와 승인 대기 수가 있다.
- **신고** (`change.register`): `+ 변경점 신고` → 설비, 4M 분류(사람·설비·자재·방법), 자주 쓰는 내용 또는 직접 쓴 변경 내용, `초물 검사 필요` → `변경점 신고`. 초물이 필요하면 그 설비의 다음 개체가 초물이 되고, 합격할 때까지 게이트 설비 투입이 대기한다.
- **승인** (`change.approve`): 초물 판정이 끝난 변경점(합격 또는 대상 아님)만 `승인`할 수 있다. 초물이 불합격이면 다시 한 초물이 합격한 뒤 승인한다.
- **수동 초물 판정** (`change.approve`): 설비가 멈췄거나 시뮬레이터가 초물을 못 낼 때 `초물 대기 설비`에서 `수동 합격` 또는 `불합격`. 확인한 시리얼을 적을 수 있다.
- 시뮬레이터가 감지하는 변경점: 교대(사람), 고장 수리·보전(설비), 자재 LOT 교체(자재), 기종 변경(방법).

### 관리계획서 `/control-plan` (품질 ▸ 관리계획서)

- 공장 정의에서 만든 AIAG 양식의 관리계획서다. 라인과 특성으로 거른다. 특별 특성은 ◆(법규·안전), ▲(핵심 기능)이고 지정마다 근거와 등급이 있다.
- `인쇄`는 A4 가로로 라인마다 새 쪽에 찍는다.

### 교대 일보 `/reports` (생산 ▸ 교대 일보)

- `교대`에서 주간(08~20시)·야간(20~08시, 한국 가상 시각)을 고르고, 라인 탭으로 거른다. 진행 중 교대는 지금까지 값이다.
- 항목: 목표(택트 기준)·투입·생산 OK(최종 양품)·폐기, 직행률, 가동·성능·양품, NG 판정, NCR 발생·종결, 4M 변경점, 초·중·종물, 인터록 거부, 비가동 사유 상위, 불량 상위, 작업지시(계획 대비 실적), 전력량.
- `CSV 내려받기`: 모든 라인을 한 파일로(엑셀용 UTF-8). `인쇄 / PDF 저장`: 브라우저 인쇄 창에서 'PDF로 저장'을 고르면 PDF가 된다. 인쇄본에는 결재란이 붙는다.

### 에너지 `/energy` (생산 ▸ 에너지)

- `최근 8시간`·`최근 24시간`·`이번 실행 전체` 중 고른다. 전력량, 가동 전력, 대기 전력 비중, 라인별·설비별·시간대별 전력량(가동·대기·정지 몫), 개당 전력량을 본다.
- 설비별 소비 전력 가정값으로 계산한 추정이다. 소비 전력 정의가 없는 설비는 `자료 없음`으로 빼고 센다.

### 보전 `/maintenance` (예지 보전)

- `예지 보전 (상태 감시)`: 상태 감시 설비 17대의 등급(`양호`·`관찰`·`경고 (보전 계획)`·`위험 (즉시 보전)`), 진동·전류·온도, 진동 추이, 건강 지수, 남은 수명(추정), 마지막 보전. 위험·경고 설비가 먼저 나온다.
- **보전 실시** (`station.repair`): `보전 실시` → 확인. 설비가 `계획 보전`으로 잠시(가상 10~60분) 멈췄다가 다시 돌고, 마모가 돌아간다. 보전 뒤 첫 개체는 초물이 될 수 있다(설비 변경점).
- 남은 수명은 표본이 적거나 추세가 잡음 수준이면 내지 않고 이유를 보인다.

### 작업자 태블릿 `/operator`

- 설비를 고르면 상태·공정 조건·작업 전 점검·알람·`초물·변경점 (4M)`이 보인다. 이 설비의 초물 대기 여부, 마지막 초물, 최근 변경점을 본다.
- `변경점 신고`(`change.register`)는 큰 버튼으로 열리는 같은 신고 양식이다.
- 정지·셋업·재가동·고장 등록은 `station.op`, 수리 완료는 `station.repair`, 점검 기록은 `check.record`가 필요하다.

### 감사 기록 `/audit` (관리자)

- 사용자 메뉴 → `감사 기록`. 새것부터 실제 시각·가상 시각·사용자·역할·동작·대상·내용·IP를 본다. 사용자와 동작(또는 동작 묶음)으로 거른다.

## 감사 기록 동작 이름

| 동작 | 남는 때 | 대상 |
|---|---|---|
| `login` | 로그인 | 아이디 |
| `login.fail` | 로그인 실패 (사용자 칸은 `anonymous`, 이유: 없는 아이디·비활성·비밀번호 틀림) | 입력한 아이디 (아이디 모양이 아니면 `(형식 밖)`) |
| `logout` | 로그아웃 | 아이디 |
| `sim.speed` · `sim.pause` · `sim.resume` · `sim.reset` | 배속 변경 · 일시정지 · 재개 · 초기화 | — |
| `sim.scenario` | 시나리오 켜기·끄기 | 시나리오 ID |
| `station.stop` · `station.setup` · `station.start` · `station.fail` · `station.repair` · `station.pm` | 설비 정지 · 셋업 · 재가동 · 고장 등록 · 수리 완료 · 보전 실시 | 설비 코드 |
| `alarm.ack` | 알람 확인 | 설비 코드 |
| `check.record` | 작업 전 점검 기록 | 설비 코드 |
| `wo.create` · `wo.update` · `wo.reorder` · `wo.cancel` | 작업지시 만들기 · 수량 고치기 · 순서 바꾸기 · 중단 | 작업지시 번호 (순서는 라인) |
| `ncr.dispose` | 불량 처리 판정 | NCR 번호 |
| `hold.create` · `hold.release` | Hold 걸기 · 해제·폐기 | Hold 번호 |
| `change.register` · `change.approve` | 변경점 신고 · 승인 | 설비 코드 |
| `change.first-article` | 수동 초물 판정 | 설비 코드 |

감사 기록 화면의 동작 필터에서 `sim*`처럼 끝에 `*`를 붙인 묶음을 고르면 앞부분이 같은 동작을 모두 본다.
